Integrated System Architecture
  • Pretrained NLP Transformers: 7-class emotion classification via DistilRoBERTa.
  • Speech Emotion Recognition (SER): Acoustic variance analysis via Wav2Vec 2.0.
  • Rule-Based Lexical Fallback: Dictionary-based scoring ensuring offline operational uptime.
  • In-Browser Microphone Support: MediaStream Web Audio recording interface.
  • Role-Based Administrative Suite: Global telemetry, user directories, and system logs.
  • Automated Database Migration: Zero-downtime SQLite schema upgrades.
  • Dynamic ReportLab Engine: In-memory PDF clinical summary generation.
  • Data Portability: Export historical user records in standardized CSV format.
